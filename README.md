### About me

I'm a Mechatronics Engineer (CEFET-MG, 2021) with a postgraduate degree in Software Engineering and Architecture (FIA Business School, 2024), working as a Software Engineer focused on functional programming, web development, distributed systems and cloud infrastructure. I build robust, secure and maintainable systems with F# and .NET, combining solid engineering with elegant design.

I've also led a small DevSecOps team, responsible for cloud infrastructure, automation, CI/CD, reliability and FinOps at a startup, where I ran short internal "Sec Talks" to promote security awareness.

Outside of work I'm into classical philosophy and theology, and I contribute to open-source in my spare time.

**Why F#?** Backed by Microsoft, built on a battle-tested and evolving platform (.NET), a great ecosystem, and a type system that [makes illegal states unrepresentable](https://blog.janestreet.com/effective-ml-revisited/), without giving up [performance](https://www.youtube.com/watch?v=NZ5Lwzrdoe8&ab_channel=JetBrains).
